# Nykaa_Bussiness_analytics
End-to-end data analytics and predictive pricing project analyzing brand catalog distribution and discount strategies on Nykaa.
🛒 Nykaa RetailIQ: Price & Catalog Analysis
This project involves data analytics and predictive modeling of e-commerce beauty product catalog data from Nykaa. Using Pandas, Matplotlib, Seaborn, and Scikit-Learn, we explore pricing structures, brand catalog distributions, and evaluate promotional discount strategies.

📌 Objective
To analyze beauty product catalog data from Nykaa and build supervised Machine Learning regression models that accurately predict final discounted prices based on original product listing prices.

💡 Key Takeaways
Core Brands Lead Volume: Market leaders like Nykaa Naturals, Neutrogena, and L'Oréal dominate catalog listing volumes.

Predictable Promotional Brackets: Strong linear relationships exist between original product prices and final selling prices across major categories.

High Predictive Accuracy: The Linear Regression model achieved a 96.5% R 
2
  accuracy score, confirming structured percentage discounting rules across the platform.
